# Pavlo Kotenko

I'm based in Cyprus. I experiment with AI and use it to make games, websites and tools. **KO RELAY** is where I publish my games.

## Projects you can try

**[SIEGE BREAK](https://ko-relay.itch.io/siege-break)** is a browser siege game about finding a fortress's weak point and bringing it down. You have a limited supply of shots. Fire, explosives and collapsing masonry change what you can target next.

The free beta runs in a desktop browser with a mouse and keyboard.

**[Home Cafe](https://homecafe.cy)** is a website I built with AI for a cafe in Polis, Cyprus. It includes the menu, opening hours and directions, with English, Greek, Ukrainian and Russian versions.

## Open-source skills

These are reusable instructions for coding agents, packaged with Python scripts and documentation. Both projects are public and MIT-licensed.

| Project | What it does |
| --- | --- |
| **[Game Release Director](https://github.com/PavloKoteno/game-release-director)** | Guides a game project through development and release preparation. Includes Godot and Steam references, 97 release controls, and a ledger for tracking checks and missing evidence. |
| **[Evidence-Driven Velocity](https://github.com/PavloKoteno/evidence-driven-velocity)** | Keeps an agent focused on finishing the requested result, then checking the assembled work and reusing checks that still apply. |

Start with the README in either repository for installation, examples and downloadable releases. If you try a skill, open an issue with what you asked it to do and what happened. That gives me something concrete to improve.
